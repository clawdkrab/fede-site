Why his name is Fede

meetFede

Fede is the pink flamingo in heart-shaped sunglasses from Macca the Gator (billed as Macca & Friends), the cartoon inside GTA 6. Rockstar hasn't printed his name anywhere public, but their website code names him: his animation is stored as Fede_AWOOGA_v02.

AWOOGA is the gag in the clip: his eyes pop out of his head as hearts. A second code file lists the panels in order and calls him "fede" again. The same system names the rest of the cast (Macca, Chunkee, Pinche), and those names are confirmed by Rockstar elsewhere.

The Collector's Box

On Rockstar's official GTA VI site, scroll to Shop, find "Collector's Box: The Vice City Collection" and click Explore Now.

https://www.rockstargames.com/VI
1

Fede's panel: bottom right

The page has eight animated panels. Fede is the bottom-right one. The page itself shows no character names; they are in the code that loads the panels.

rockstargames.com/VI › Shop › Explore Now
2

The code names him Fede

A code file on the same site lists every animation on that page. The flamingo's is stored as videos/ce/Fede_AWOOGA_v02. Open it, press Cmd+F, search Fede_AWOOGA.

https://www.rockstargames.com/VI/_next/static/chunks/16g7lr_v.3drd.js
3

A second file calls him "fede"

A separate file sets the animation order: plane, chunkie, sunny, fede, palm, pinche, lowrider, macca. Written for a different job, it uses the same name.

https://www.rockstargames.com/VI/_next/static/chunks/080g1zt0g7.7h.js
4

The clip matches the file name

The file is a video on Rockstar's server: the flamingo's eyes pop out as hearts, the classic cartoon "AWOOGA!". The file name describes this exact clip.

https://www.rockstargames.com/VI/_next/static/media/1280_av1.0f8g082hdvi8t.mp4
